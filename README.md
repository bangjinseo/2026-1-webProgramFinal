# finalExam

Separate React project space for the final exam.

This folder contains the Apple Localization Lab MVP. Supabase is intentionally not connected yet.

## Structure

- `src/pages`: route-level screens
- `src/components`: reusable UI components
- `src/layouts`: app-level layouts
- `src/services`: future service clients and API logic
- `src/hooks`: reusable React hooks
- `src/data`: static or local data
- `src/styles`: global styles and design tokens
- `src/assets`: images, icons, fonts, and other assets
- `src/lib`: framework-independent helper modules
- `public`: static public files
